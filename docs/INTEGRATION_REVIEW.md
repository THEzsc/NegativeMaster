## 整合修正

- `gui.py` 同时注册档案与影调工作流接口；忽略规则同时保留原生构建产物和私人档案目录。
- 原生 Python 桥接复用共享解码函数，接受新增的第三个解码参数；避免合并后预览或分析抛出参数错误。
- 原生应用构建脚本加入平台、档案、图案和影调模块；独立临时资源目录的导入测试证明不会依赖仓库外的模块副本。
- 原生运行时的档案目录跟随 `NM_DATA_ROOT`，不会写入应用资源包。
- 扩展图案字段时兼容旧版档案，旧数据库仍能搜索；编辑卷信息保留封面署名、来源和许可。
- 图案保存期间串行处理选择，网络失败后可重试，较晚的返回不会把用户切回另一卷。

## 图案资料

内置 74 张获许可的暗盒实物照片，37 组品牌／型号名称；另索引 730 条原始包装扫描。可确认记录关联至现有资料库中的 66 款胶卷，其余保留历史名称。图片来源、逐张署名、许可、版本边界及未复制的参考网站，见 [ARTWORK_SOURCES.md](../data/ARTWORK_SOURCES.md)。
