# 胶片档案

在工作台顶部打开「胶片档案」，或访问本地服务的 `/archive`。此工作区与调片、整卷排版共享型号资料库和昼夜主题，档案保存在本机 SQLite 数据库中。

## 从一卷开始

1. 点击「新建一卷」，记录名称、编号、胶卷型号、规格、标称 ISO 与实拍 EI。
2. 填写拍摄起止日期、地点、相机、镜头，添加标签和这一卷的故事。
3. 使用「待拍摄 → 拍摄中 → 冲洗中 → 待扫描 → 已归档」记录进度；状态可随时手动修改，不会自动判断照片是否已冲洗。冲洗工艺、实验室、药水/温度/时间/增减感及底片存放位置各自保存。
4. 点击「关联照片文件夹」，填写本机完整路径。默认只关联文件名以 `_pos` 结尾的成片；也可选择全部图片。一次只读取该文件夹，不递归子文件夹，一卷最多 240 张。按文件名自然排序，重复路径自动跳过。
5. 打开照片可评分、写备注、设为封面或移除关联。搜索覆盖名称、编号、型号、地点、相机、镜头、标签与备注，可叠加年份/进度筛选。

档案只读取源图并生成独立 JPEG 预览（最长边 1200px），不会复制、覆盖、移动或删除源图，也不修改 XML 调片参数。这里按原样显示成片，不会把负片自动反转；RAW 只保留源文件关联，建议先在调片区导出成片。归档预览用于浏览，不替代原始照片或用于色彩校准。

## 封面与胶卷盒

- 100 款胶片资料复用 `data/film_stocks.json`，详情里保留各型号已有的产品和考据链接。
- 默认封面是由程序绘制的文字档案标签，明确标为「非原厂包装」。不将现代包装、重绘图或近似字形当作历史实物证据。
- 左侧「浏览暗盒图案库」可查看 74 张内置实物照片，按品牌、型号搜索；在「封面 / 胶卷盒 → 从暗盒图案库选择」进入时，默认匹配当前卷的型号和规格。没有匹配项可切到全部型号。不同年代与视角分开保留，选择前可放大并查看来源。
- 「用作封面」保存独立预览，自动记录作者、来源与许可；编辑胶卷资料不会清掉这些信息，ZIP 备份也会保留。尚未选定胶卷时可以浏览，但不能保存封面。保存期间所有图案选择按钮暂时禁用，失败后可重试。
- 「包装扫描资料」收录 730 条外部扫描索引，按名称、ISO 或有效期搜索。扫描链接与内置可用图片分别展示，不自动下载未确认再分发许可的图片。来源范围及逐张署名见 [ARTWORK_SOURCES.md](ARTWORK_SOURCES.md)。
- 可拍下自己的胶卷盒，上传 JPEG、PNG、TIFF、WebP 或 BMP（不超过 20 MB / 1 亿像素），填写拍摄者/署名和来源网页。只保存经过重新编码的预览，来源地址仅用于记录，不触发远程下载。也可用本卷的任意可预览照片作为封面。
- 2026-10-16 核验：[Kodak GOLD 200 官方产品页](https://www.kodak.com/en/still-film/product/consumer/gold-200-film/)列出 135 和 120 产品规格，可作为型号信息和包装资料的查找入口。未将该网站图片作为应用资产打包，也未假定网站图片获得了再分发许可。
- 其他既有型号链接的证据范围见 [FILM_SOURCES.md](FILM_SOURCES.md)。链接是资料来源，不能代表所有年代、地区与批次的包装相同。

## 存储、备份与迁移

默认目录是仓库中的 `archive_data/`，已加入 Git 忽略。可用环境变量 `NEGATIVEMASTER_ARCHIVE_DIR` 指向固定的本地数据目录，避免换分支或移动工作目录时误以为档案丢失。应用在第一次访问档案数据时建库；只打开调片界面不会创建档案数据库。

目录内包含 `archive.sqlite3`、运行期间的 SQLite WAL/SHM 文件，以及 `assets/` 中按 SHA-256 命名的 JPEG 封面与预览。请求使用独立数据库连接；更新资料会检查版本，遇到另一窗口的修改时提示重新打开，避免静默覆盖。

「备份档案」下载版本化 ZIP，包含所有胶卷资料、照片路径/备注/评分、封面和预览，**不包含原始照片**。请同时对原始照片和调片参数做独立备份。ZIP 的最大体积是 256 MB、清单上限 16 MB、最多 10000 卷；超出时关闭应用，然后复制完整档案目录。数据库运行时可能使用 WAL，手动复制前应停止应用，不能只复制正在使用的 `.sqlite3` 文件。

「恢复备份」先校验格式、路径、图片哈希、图片尺寸和容量，再在事务内写入资料。恢复以新 ID 添加胶卷，**不会覆盖已有档案；重复恢复会产生副本**。ZIP 内不会执行路径提取，也不会打开清单中的源照片路径。备份中的拍摄/冲洗日期、署名和源路径保留；新增副本的创建/修改时间以恢复时为准。

源文件离线时仍可浏览已存预览。移动照片或更换电脑后，在「关联照片文件夹」中填写新目录并点击「重连已迁移照片」：按唯一的原文件名重新关联，保持评分、备注与既有预览。同名冲突会跳过，文件内容不会猜测匹配；需要改变图片本身时移除旧关联后重新导入。备份中的平台路径不自动换算。

删除档案或移除关联只删除数据库记录，原图保持不变。暂不自动清理失去引用的预览文件，避免后台清理与备份/恢复并发时误删；这些预览不会再通过图片接口公开，也不会包含在后续 ZIP 中。可以关闭应用后恢复备份到一个新的空目录来整理预览库。

## 当前边界

这是可用的本地档案基础版，不包含云同步、地图定位、人脸识别、自动 EXIF 填表、逐张拖拽排序、原片完整性校验或运行时厂商封面抓取。调片、排版与档案各自保留数据；档案不自动把元数据写回文件或生成排版项目。共享顶栏可切换工作区。多窗口允许浏览与编辑，冲突的胶卷资料保存会明确拒绝；照片备注采用最后一次保存。
